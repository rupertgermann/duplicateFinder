# Triage labels

| Role | GitHub label | When to apply |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The maintainer has decided to close the request without implementing it. |

When a skill names a triage role, apply its GitHub label from this table.
